## 判定状态枚举（v1.2起，v1.3保留）

| 状态 | 含义 | 使用条件 |
|---|---|---|
| 🟢 未触发 | **取数完成且未触发** | 判定所需数据已按**注册口径**取到、已复核，读数未达触发条件 |
| 🟡 黄灯 | 置顶提示+复核动作 | 读数达触发条件，执行预注册指定复核动作 |
| 🔴 红灯 | 置顶+复核+等用户拍板 | 读数达红灯条件，写明预注册含义与建议动作 |
| ⏸️ 暂缓 | 数据源不通，无法判定 | 按预案降级后仍取不到数，日报标注"数据源待开通"，**不**用估算/网搜顶替 |
| ⏳ **待判读** | 数据已披露但本轮未取数复核，**或注册口径数据不可得** | 判定所需数据已公开披露但本轮未实际取数/复核；**或注册口径的数据取不到、无法按注册口径判定**。不得标🟢。下轮取数后转为🟢/🟡/🔴 |
| 序列积累中 | 分位/连续性类条件样本不足 | 按宪法第五条，样本<20个观测时分位暂缺、连续性暂无法判定，报当日单日读数 |

**v1.2关键变更**：🟢语义从"未触发"收紧为"**取数完成且未触发**"。数据已披露但没取数复核的，标⏳待判读，不许用🟢占位。

## 口径纪律（v1.3新增，与宪法同级）

1. **判定口径必须与注册口径一致**：每条信号注册时写明的变量口径（什么指标、什么公司、什么业务分项、什么报告期），就是判定时唯一有效的口径。
2. **注册口径数据不可得时，禁止用代理口径判定**：取不到注册口径的数据（如公司未披露分项、连接器不返回该字段），一律标⏳**待判读**，并注明"缺什么口径、何时可得"；**不得**用总营收代替分项、用同业代替本公司、用估算代替披露值来凑出一个🟢/🟡/🔴。
3. **参考注脚不参与触发**：信号中列为"参考/注脚"的口径只供背景参考，不进入触发条件的逻辑运算。
4. 判定结论必须写明：实际取到的是什么口径、是否与注册口径一致；若不一致，按本条第2点标⏳待判读。

### 信号1-2口径说明（v1.3重注册）
- **主口径（参与触发）**：澜起科技"互连类芯片"营收同比增速——这是澜起中报/年报的官方披露分项，口径明确、可溯源。
- **参考注脚（不参与触发）**：聚辰股份SPD/DDR5接口芯片出货与营收情况。聚辰半年报未单独披露SPD收入同比（iFinD不返分项、公司财报只有出货量环比定性描述），在该分项数据可定期披露前，仅作层①需求侧背景参考，不进入1-2触发判定。
- 历史教训：v1.2时期曾用聚辰总营收同比（+4.71%）代理SPD分项判🟢，违反"判定口径必须与注册口径一致"——总营收含EEPROM/NFC/NOR等非接口业务，不能代理接口芯片分项。v1.3起明确禁止此类代理判定。

### 信号3-2双轨显示规则（v1.3微调）
- 事件轨与数值轨**各自独立标状态**，不合并为一个🟢。
- 事件轨：每日公告扫描后标——有新增质押公告标🟡，无则标🟢。
- 数值轨：月末扫描前标"**月频未到期**"（不是🟢，也不是待判读——是未到该轨的判定时点）；月末取数后按阈值标🟢/🟡/🔴。
- 日报信号板3-2行写两个状态，如"事件轨🟢 ｜ 数值轨：月频未到期"。

### 信号5-2数据源三级执行预案（v1.1定版）
1. **第一级**：iFinD批量取核心池资金字段；
2. **第二级**：不通则降级为"512480半导体ETF日频资金净流入连续3日为负"（单只ETF一次调用）；

## 贴线纪律（宪法第四条）
读数到达阈值的**90%区间**即为【接近】状态，当日日报必须升级提示，不许等真触发了才第一次提。

## 分位纪律（宪法第五条）
任何"历史分位"类阈值，样本不足**20个观测**时一律标"样本积累中，分位暂缺"，先用逻辑锚顶替，分位锚随时间序列积累后补挂。不许在样本不足时硬算分位。

## 触发动作三级（宪法第六条）
- 🟢 正常 = 照常记录
- 🟡 黄灯 = 当日日报置顶提示 + 执行预注册指定的复核动作
- 🔴 红灯 = 置顶 + 复核 + 写明"这条信号预注册时的含义和建议动作"，然后**等用户拍板**。
