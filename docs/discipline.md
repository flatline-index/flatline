# 纪律军规

这份文档不是操作手册,是"为什么这么做"。技术上跑通数据管道只是及格线,真正决定这套
监测体系有没有用的,是下面这几条纪律有没有被诚实地执行。每一条都是用来对抗人性弱点的
(事后诸葛、锚定情绪、把感觉当证据),不是用来炫技的。

## 1. 预注册信号 + 收盘口径

在你还没被行情牵着情绪走的时候(建仓前,或者至少在冷静的时刻),把三件事写清楚并存
进快照文件:
- **论点**:一句话,可证伪
- **证伪线**:什么条件出现,论点就算错了
- **再进场/加仓条件**:证伪线触发后,要看到什么条件才允许重新考虑

**收盘口径**:证伪线、触发条件一律用收盘价判定,盘中触碰不算数。原因很直接——盘中
经常有插针、假突破,一旦允许"盘中摸到就算数",噪声会大量污染你的判断;收盘口径的
代价是会慢一点反应,这是刻意的取舍,不是疏漏。

**预注册不可越权改**:条件一旦写进快照,AI 助手或者任何自动化流程,只负责拿新数据
去对照这些条件、给出"成立/未触发"之类的状态,**不能顺手帮你优化或修改条件本身**。
只有你自己能改自己预注册的规则——而且理想情况下,修改也应该在冷静的时候做,不是在
"眼看就要触发了,是不是应该调松一点"的心态下做。这条纪律存在的意义就是防止规则被
行情实时腐蚀。

## 2. 历史分位不足禁止编数

要给一个指标打"历史分位"(比如"这是过去 60 天里的第 15 百分位"),前提是有足够的
历史样本。样本不够时,唯一诚实的写法是:

> 历史不足 N 天,分位暂缺

不许凭感觉估一个数("这个读数感觉是近期偏高吧,大概 80% 分位")。人对"这个数字算不算
极端"的直觉普遍不可靠,尤其容易被最近发生、印象深刻的极值锚定。样本不够就是不够,
宁可留白也不许拍脑门。每个脚本都内置了各自指标的最小样本量阈值,不满足就打印这句话,
不是脚本的 bug,是设计。

## 3. 口径三问

每次报出一个数字,先问自己三个问题,至少把最相关的那个说给听众/自己听:

1. **统计边界**:这个数字精确统计的是什么,不包括什么?(例:OpenRouter 的 Token 量
   只统计经该平台路由的流量,不是全球 AI 推理总量,更不含各厂商自家应用的直连流量)
2. **样本有没有偏移**:这个指标的统计口径、统计范围,历史上有没有变过?变过的话,
   跨越变化点的绝对水平对比是没有意义的,必须分段看(例:KOFIA 强平金额 2023-10-25
   前后的口径切换)
3. **水平还是趋势**:这个数字的绝对值本身有意义,还是只有变化方向/相对分位有意义?
   (例:CDS 近似利差、自建流动性代理利差,都只能跟自己的历史序列比,不能跟专业终端
   的精确口径比绝对水平)

这三问不是走过场——播报里带一句口径说明,是为了防止"数字本身没错,但因为没交代
统计边界/口径断点/水平还是趋势,读的人得出了错误结论"。数字真、视角错、结论歪,是
最容易被忽视的一类错误,因为它不会报错,只会悄悄误导。

## 4. 阈值必须回测,不能拍脑门

任何形如"这个指标跌破 X% 就是信号"的判读线,在写进预注册条件之前,都要能回答:
**这条线的历史依据是什么?** 具体做法见 `docs/backtest-method.md`,核心是四步:定义
事件 → 看历史上每次触发之后市场实际怎么走 → 识别统计口径断点(避免跨断点硬比较)
→ 诚实报告样本量。

配套的诚实要求:多数这类回测的样本量都很小(个位数到十几个历史事件很常见),这是
"给阈值找一点历史证据"的最小流程,不是统计学意义上的严谨检验。不要用"回测过"这个
说法给判读线镀金,样本量必须跟结论一起报出来。

## 5. 减速不等于转跌

一个指标的**增长率在放缓**(比如同比增速从 +80% 降到 +40%),和这个指标**掉头向下**
(同比转负、绝对值开始下降),是两件完全不同的事,却经常被叙事混为一谈。前者是"二阶
导数变负,一阶导数仍是正的";后者才是真正的"一阶导数转负"。只有后者才构成趋势逆转。

这条纪律尤其适用于层①需求侧一类的增长型指标:媒体和市场情绪很容易把"增速放缓"直接
翻译成"见顶了/不行了",播报时必须把"还在涨,只是涨得慢一点"和"真的开始跌了"说清楚
区分开,不能含糊带过。

## 6. 现货-合同价差与周期时钟法(供给侧监测的通用方法)

这是一种通用的供给侧监测思路,适用于任何"同一种标的物同时存在现货价格和合同
(定期重订)价格"的市场(大宗商品、部分工业中间品等),不点名任何具体研报或数据
提供方——方法本身是公开可推导的逻辑,不是谁的专利:

- 现货价持续高于合同价 → 卖方在下一轮合同重订价时更有议价权,合同价大概率上修(或至少
  跌得更慢)
- 现货价持续低于合同价 → 买方更有议价权,合同价大概率下修
- 把"现货-合同价差"当**领先指标**看,把"合同价本身的修订方向"当**滞后/确认指标**看,
  而不是反过来只盯着合同价的绝对水平做判断——等合同价真的动了,往往已经滞后一整个
  重订周期

**局限**:这是一个在类大宗商品市场里反复出现的经验模式,不是放之四海皆准的定律。
现货市场流动性/透明度不足时(挂单稀疏、成交不连续),这个价差本身的噪声会很大;
合同条款里如果包含非价格条款(长期协议里的产能保证、优先供应权等),现货-合同价差
和合同价修订方向之间的领先关系也会被削弱。用之前先确认你监测的市场现货侧足够活跃。
