# 建盘指南:从零立一个盘

> 一个"盘"=一个投资主题的完整观测体系。本指南六步,配合你的 AI Agent 执行;每步末尾标注了验收要点。实测:一个熟悉方法论的人带一个能执行任务的 Agent,从零到第一份日报约需五到七轮对话。

## 第 0 步:先给 Agent 立规矩

把 [agent-discipline.md](agent-discipline.md) 完整交给你的 Agent,并要求它:今后每轮先列执行步骤再动手、每步亮工具名、失败如实标。**规矩立在任何取数之前。**如果你的 Agent 有可配置的数据工具(插件/连接器),先做一轮最小联通测试:每个工具只调一次、只取一个数,证明通路,同时让 Agent 交一张《工具分工表》——每个工具能拿什么数据、什么场景用、输入输出长什么样。你来批改这张表,批改后的版本就是它的取数章程。

**验收要点**:联通测试里失败的工具,Agent 是如实报错还是硬凑了数?这是它可不可信的第一道检验。

## 第 1 步:定盘的主题与标的池

主题要具体到"一条产业链/一个赛道",不要宽到"科技股"。标的池按产业链环节分组(例:原厂/设计/模组/设备/材料/封测),每环节 2-5 只候选,然后分两层:**核心池**(每环节 2-3 只,日频跟踪,总数控制在 15 只以内)+**观察池**(其余,周频)。分层不是偷懒,是配额纪律:全池日频会把取数额度烧在低信息量的标的上。

选标的时的三个纪律:标的的"纯度"(主营与主题的相关收入占比)逐只标注把握度,拿不准标"待验证";时效性事实(是否上市/代码)现查不凭记忆;周期股的低市盈率不作为"便宜"的依据(盈利暴增期的周期股市盈率天然低,那是周期位置不是安全边际)。

**验收要点**:池子里有没有"蹭概念"标的?每只的把握度标注有没有依据?

## 第 2 步:把五层四问翻译成可观测变量

对每一层问:"这个问题,用什么数据能回答?"每层 2-4 个变量,每个变量写清四栏:**用什么工具/问法取、更新频率(日/周/月/季)、为什么它能回答这一层(一句话)、定版时点(几点之后取到的数算定版)**。

三条设计经验:

- **接受某层天然偏薄**。不是每个市场每一层都有好数据(例:A 股的下游需求数据远不如美股财报体系),如实标注"本层以 X 为主、数据偏薄",比硬凑弱代理诚实。
- **跨市场锚常常是最强变量**。如果你的主题有海外定价上游(例:A 股存储链的定价上游是海外存储周期),每天开盘前的隔夜海外锚(相关美股/指数涨跌)应该是日报固定序章。
- **加一条相对强弱**。核心池等权涨跌减去行业大盘基准(选指数不选单股,单股的独立风险会污染基准),回答"今天的行情是主题独立行情还是行业普涨"。

**验收要点**:每个变量的"为什么"那一栏,能不能讲给外行听懂?讲不出来的变量删掉。

## 第 3 步:数据源落地

拿着变量清单找数据源,原则:

1. **免费公开优先,已验证优先**。海外市场见 [data-sources.md](data-sources.md)。
2. **每条序列单源**。备源只在主源死掉时降级启用,永不混拼。
3. **只认原始数据平台,不认媒体转述**。报价类数据必须来自报价平台原文,并记录"报价来源+报价日期"。
4. **让 Agent 自己写它环境里能跑的取数方式**。路标给"哪里有什么数据",代码由 Agent 按自己的执行环境生成——别人的脚本在你的环境里多半是死文件。
5. 取不到的变量诚实挂"数据源待开通",在日报里长期显示缺口,别让缺口从视野里消失。

**验收要点**:每条数据腿的定版时点写清了吗?口径注(统计范围/滞后/近似性质)写了吗?

## 第 4 步:跑基线,写预注册

先跑一次**基线快照**:每个日频变量取当前值,存为体系第一份数据存档——没有基线,阈值就是拍脑袋。

然后写**信号预注册表**:每层 1-3 条,全体系 8-12 条,宁缺毋滥。每条四栏:变量/触发条件/触发动作/为什么定这个阈值(拿基线数据或常识说理)。要点:

- 起步全部用**逻辑锚**(环比连续 N 期低于 X、事件发生即触发、破某结构位),历史分位等样本攒够了再补挂。
- 防守信号与过热信号**两边都要有**——风险信号防亏钱,过热信号防追高。
- 阈值给缓冲带,防单期噪音误触发(例:"连续两个月低于 +5%"而不是"单月转负")。
- Agent 拿不准的数值,让它标"提案:X,依据不足,请定夺"——**不许它硬编,也不许你不裁决**。
- 你批改、你签字、定版。从这一刻起规则归版本管理,谁也不许顺手改。

**验收要点**:每条信号盖住了"触发了怎么办"吗?红灯动作是不是都落到"把决定递到人面前"?

## 第 5 步:日更

日报固定结构:**校时头部**(生成时点/数据基准日/定版状态)→ **海外锚序章**(如适用)→ **核心池行情表**(含等权与相对基准超额)→ **当日异动**(全池唯一逆向+放量/高换手类组合升格呈现)→ **五层各段**(有更新的报读数+判读;低频变量没更新也要出现,报"登记值+下次更新时点")→ **信号判定板**(预注册表逐条过,附判定依据数值)→ **明日看点**。

日更纪律:呼出即跑、第一步校时;判定只用定版数据;低频数据每天重复报登记值(它的价值是"每天让你知道现状",不是"有更新才提");当日数据追加进时间序列表(一张宽表,与快照分工:快照管判读,宽表管数据曲线)。

播报三条(写给读报告的人,包括未来的你自己):**自包含**——每个指标出现时带一句"它是什么、干什么用",读数配一句"这个数意味着什么",自造的简称当场展开成人话,报告要写给"聪明但没背过你术语表的读者";**趋势三点**——趋势类指标报"今日+约一周前+约一月前"三个点,单点数字没有方向感;**置顶 lede**——当天最重要的一条盘面信息放报告最前面,别让读者从流水里自己找重点。

**先手动跑通至少两个交易日,再谈定时自动化**——而且自动化要按宪法第七条走审批。

## 第 6 步:复盘闭环

每份快照留复盘区,三类事必须记:数据口径踩的坑(哪个源给过脏数据、哪个字段口径漂移)、信号的表现(哪条误报了、哪条贴线时没升级提示)、规则变更史(改了什么、为什么、谁批的)。监控范围每暴露一次盲区,扩一次——**盲区的代价只有在复盘里被具体化,体系才会长大**。

最后,拿 [checklist.md](checklist.md) 整体过一遍。过不了的项,别欺骗自己"以后再补"。
